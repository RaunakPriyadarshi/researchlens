# ResearchLens — Research Paper Classification Website

A Streamlit website for the existing Scopus abstract classification project. It predicts one of:
- Science
- Business
- Social Science

It supports one abstract at a time and batch CSV uploads.

## Important: add your trained model

The trained model is created inside your Google Colab notebook. It is not recreated by this website.

1. Open `Individual_Project.ipynb` in Google Colab.
2. Run the notebook through the **Save the final model** cell (the cell that runs `joblib.dump(final, "best_model.joblib")`).
3. In Colab's left Files panel, find `best_model.joblib`.
4. Right-click the file and choose **Download**.
5. Put the downloaded `best_model.joblib` in this project folder, beside `app.py`.

The final model contains the fitted TF-IDF vectorizer and Logistic Regression classifier. The app also repeats the notebook's text-cleaning rules, including its stopword list.

## Run locally on Windows

Install Python 3.10 or 3.11 if possible, then open PowerShell in this folder:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

If PowerShell blocks activation, use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

Streamlit will show a local URL, usually `http://localhost:8501`.

## Test the app

### Single abstract
Choose **Single abstract**, paste a full abstract, and click **Classify abstract**.

### CSV upload
Choose **Batch CSV** and upload a CSV containing a column named `Abstract` or `text` (case-insensitive). The output preserves original columns and adds:
- `predicted_label`
- `confidence` (when the classifier supports `predict_proba`)

Download the resulting CSV from the app.

## Deploy free with Streamlit Community Cloud

1. Create a GitHub repository, for example `research-paper-classifier`.
2. Upload `app.py`, `requirements.txt`, `README.md`, and `best_model.joblib`.
3. Ensure `best_model.joblib` is actually present in the repository before deploying.
4. Open https://share.streamlit.io/ and sign in with GitHub.
5. Choose **Create app**, select your repository, branch (`main`), and main file path (`app.py`).
6. Deploy and wait for the build logs to finish.
7. Open the generated `*.streamlit.app` URL and test both single-abstract and CSV workflows.

### Model file size / GitHub
If GitHub rejects `best_model.joblib` because it is too large, don't commit it through ordinary Git. Use Git LFS or store the model in an appropriate model-artifact host and update `app.py` to retrieve it securely at startup. Never upload private data or secrets to a public repository.

## Troubleshooting

- **Model missing:** `best_model.joblib` must sit in the same folder as `app.py`.
- **NLTK download error:** the app needs to download NLTK `stopwords`, `wordnet`, and `omw-1.4` the first time it runs. If hosting blocks downloads, bundle the NLTK data and configure its data path.
- **Module not found:** activate the virtual environment and run `pip install -r requirements.txt`.
- **Prediction errors:** use the same preprocessing rules as the notebook and a model file generated by that notebook.
- **Wrong CSV column:** rename your abstract column to `Abstract` or `text`.
